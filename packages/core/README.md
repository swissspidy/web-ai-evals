# @web-ai-evals/core

Shared types, JSONL dataset loading, prompt templates and stats for
[web-ai-evals](https://github.com/swissspidy/web-ai-evals). You normally get it as a dependency of
`@web-ai-evals/runner`. Import from it directly for the run file types
(`RunFile`, `CellResult`, …) when you process results yourself.
